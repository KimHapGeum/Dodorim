# 두드림 (Dodorim)

> 디지털 기기 사용이 익숙하지 않은 사용자를 위한 종합 전자기기 교육 플랫폼

해당 프로젝트는 
오산대학교 컴퓨터 소프트웨어 학과 캡스톤 디자인 프로젝트로 제작됨

---
## 팀 개요

두드림 팀은 누구나 키오스크, 병원 접수 등 일상 속 디지털 기기를 편하게 사용할 수 있도록 돕는 교육 서비스를 만들었습니다.

| 이름 | 역할 | 담당 |
|---|---|---|
| 오세준 | 팀장 | 기획 및 프로젝트 관리 |
| 김태우 | Frontend | 사용자·관리자 화면 구현 |
| 김동훈 | Backend | API 및 데이터베이스 구현 |
| 장건우 | Document | PPT 제작 및 문서 제작 |

---
# 브랜치 설명

- main 브랜치: 단순 html 로 구현되어있는 레거시 웹 사이트 파일
- app 브랜치: 플러터 기반으로 구축된 어플리케이션 파일
- webful 브랜치: main벤치를 React 기반으로 구축한 파일과 Node.js로 구축된 서버 종합파일
- webful2 브랜치: webful벤치를 NAS에 호스팅되어있는 최신파일

## 프로젝트 소개

두드림은 학습자가 주제와 장소를 선택해 전자기기 사용 방법을 단계별 강의로 배울 수 있는 웹 플랫폼입니다. 관리자는 강의, 단원, 공지사항, 배너, 건의사항을 관리할 수 있습니다.

### 주요 기능

- 주제 → 중단원 → 소단원 → 강의 순서의 단계별 학습
- 키오스크, 병원 등 상황별 전자기기 교육 콘텐츠
- 텍스트 음성 안내(TTS)
- 관리자 페이지를 통한 강의·단원·공지·배너 관리
- 학습자 건의사항 접수 및 처리 상태 관리

## 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | React, Vite, React Router |
| Backend | Node.js, Express |
| Database | MariaDB |
| File Upload | Multer |
| Deployment | Docker Compose |

## 실행 방법

### 1. 백엔드 실행

```bash
cd Dodorim-server
cp .env.example .env
npm install
npm run dev
```

### 2. 프론트엔드 실행

```bash
cd Dodorim-react
npm install
npm run dev
```

- 프론트엔드: `http://localhost:5173`
- 백엔드: `http://localhost:3000`

## 화면 예시

| 학습자 화면 | 관리자 화면 |
|---|---|
| 주제 선택, 장소 선택, 강의 목록, 강의 보기 | 강의·단원·공지·배너·건의사항 관리 |

## 맡은 역할

| 구분 | 내용 |
|---|---|
| 기획 | 사용자 대상 분석, 학습 흐름 및 기능 정의 |
| 디자인 | 화면 구성, 아이콘 및 콘텐츠 디자인 |
| 프론트엔드 | 학습자·관리자 UI, API 연동 |
| 백엔드 | REST API, 인증, 파일 업로드, DB 설계 |

## 기대 효과

- 디지털 기기 사용에 대한 접근성 향상
- 반복 학습을 통한 디지털 소외계층의 자신감 향상
- 관리자가 교육 콘텐츠를 쉽게 등록하고 갱신할 수 있는 운영 환경 제공
