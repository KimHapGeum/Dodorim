* 두드림 Project

해당 프로젝트는 
오산대학교 컴퓨터 소프트웨어 학과 캡스톤 디자인 프로젝트로 제작됨

---
* 팀 개요

. 팀명: Nova
. 팀장: 오세준
. 팀원: 장건우, 김태우, 김동훈
. 주제: 실버세대를 위한 전자기기 교육 웹사이트 및 어플리케이션

---
* 브랜치 설명

. main 브랜치: 단순 html 로 구현되어있는 레거시 웹 사이트 파일
. app 브랜치: 플러터 기반으로 구축된 어플리케이션 파일
. webful 브랜치: main벤치를 React 기반으로 구축한 파일과 Node.js로 구축된 서버 종합파일
