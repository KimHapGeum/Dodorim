# 두드림 체험하기 페이지 (React)

실버세대를 위한 전자기기 체험 페이지입니다. 세로 직사각형 '스마트기기 체험관' 패널에서 6가지 체험(키오스크 · 테이블형 키오스크 · 무인민원발급기 · 셀프 계산대 · 병원 · 종합병원)을 고르면 바로 체험 화면이 열려요.

**체험 방법** (체험 화면 위쪽 탭으로 바꿀 수 있고, 처음에는 '자유롭게 해보기'로 열려요)
1. **알아보기** – 기계의 각 부분(화면, 카드 넣는 곳, 출력구 등)을 차례로 테두리로 짚어 설명
2. **자유롭게 해보기** – 실제 기계처럼 직접 눌러 보고, 막히면 '힌트 보기'(안내 문장 + 누를 곳 반짝임)

(연습하기·미션 채점 코드는 각 파일의 `MISSION`에 남아 있어서, 나중에 `ExperiencePage.jsx`의 `MODES`에 다시 넣으면 살아나요.)

| 체험 | 기계 모양 | 실제 흐름 |
|---|---|---|
| 키오스크 | 흰 몸체 + 검은 유리 세로 화면, 영수증 프린터·바코드 리더·카드 단말기 | 터치 → 결제수단 먼저 선택(현금 없는 매장) → 2열 메뉴·이전/다음 넘기기 → 세트 사이드·음료 고르기 → 총주문내역 → 결제하기 → Step1 포장/매장 → 얼음 옵션 → Step2 할인/적립 → Step3 결제 → 카드 넣기 안내 → 주문번호 영수증 (패스트푸드점 키오스크 흐름 참고, 상호·로고·메뉴 이름은 사용 안 함) |
| 테이블형 키오스크 | 흰 테두리 가로 태블릿 + 아래 카드 리더기 | 대기화면(단계 안내) → 왼쪽 메뉴 목록 · 사진 메뉴 → '장바구니에 담으시겠습니까?' → 장바구니 → 결제방법(카드/현금/나눠 내기) → 할부 → 주의 안내 → 카드 읽히기 → 5만 원 이상 서명 → 주문 완료 (식당 테이블 주문기 흐름 참고, 회사 이름·로고·사진은 사용 안 함) |
| 무인민원발급기 | 검은 본체(QR·무인 민원발급창구) + 오른쪽 결제 부스 | 증명서 분류 → 서류 → 주민번호 → 지문 → 발급 내용 → 부수 → 현금/카드 → 증명서 나오는 곳 |
| 셀프계산대 | 모니터 + 받침대 프린터 + 카드 단말기 + 손잡이형 바코드 스캐너 | 시작하기 → 결제 방법 먼저 선택 → 종이봉투 선택 → 상품을 끌어 스캔대에 놓고 스캐너를 끌어 대면 '삑' → 멤버십 포인트 → 카드 결제 → 영수증·소지품 안내 (생활용품점 계산대 흐름 참고, 상호·로고는 사용 안 함) |
| 병원 키오스크 | 흰 스탠드형, 물리 숫자 키패드·카드·출력구 | 접수(본인확인→진료과→선생님→접수증) / 수납(진료비→카드→영수증·처방전) |
| 종합병원 | 흰 스탠드형, 진료카드 리더·카드·출력구 | 접수하기(번호 입력→본인 확인→진료과목→접수완료 안내판→접수증 출력→5초 후 처음 화면) / 수납·처방전(번호→진료비→카드→영수증·처방전) (종합병원 무인 접수기 흐름 참고, 병원 이름·로고는 사용 안 함) |

## 어르신용 기능
- **도우미 안내**: 단계마다 무엇을 눌러야 하는지 큰 글씨로 알려줘요.
- **누를 곳 반짝이기**: 다음에 눌러야 할 버튼이 노랗게 반짝여요. (켜고 끌 수 있음)
- **소리로 안내 듣기**: 안내 문장을 한국어 음성으로 읽어줘요. (브라우저 음성합성)
- **실제 기계 하드웨어**: 카드 투입구, 바코드 스캐너, 영수증·서류 출력구, 지문인식기, 동전·지폐 투입구를 화면 밖 기계 몸체에 그려서 실제처럼 "꽂고, 빼고, 꺼내는" 동작을 연습해요.
- **실제 함정 재현**: 현금 없는 매장, 세트 추가금(~), 얼음 옵션, 2인분 이상 메뉴 등.
- 기계 크기는 화면에 맞게 자동으로 확대·축소돼서 휴대폰·태블릿·PC에서 모두 보여요.

## 기존 프로젝트에 넣는 법
1. `src/experience` 폴더를 프로젝트의 `src` 안에 그대로 복사하세요.
2. 라우터에 연결하세요 (react-router 예시):

```jsx
import ExperiencePage from './experience/ExperiencePage';

<Route path="/experience" element={<ExperiencePage />} />
```

3. "체험하기" 버튼에서 `/experience` 로 이동시키면 끝이에요.

### 옵션
- `<ExperiencePage initial="civil" />` : 특정 체험을 바로 열기 (`kiosk`, `table`, `civil`, `self`, `hospital`, `general`)
- `<ExperiencePage onHome={() => navigate('/')} />` : 선택 화면 왼쪽 위에 '홈으로' 버튼 표시

## 참고
- 추가 라이브러리 없이 React 18만 사용해요. (CSS는 `experience.css` 하나, 모든 클래스가 `.dd-exp` 안에서만 적용돼 기존 스타일과 충돌하지 않아요)
- 상호명(두드림 버거·두드림 식당·두드림마트·두드림병원)과 가격·수수료는 체험용 가상 값이에요. 각 파일 위쪽의 `ITEMS`, `DOCS`, `DEPTS` 배열만 고치면 바뀌어요.
- 미션 내용과 채점 기준은 각 파일의 `MISSION`, 알아보기 순서는 `TOUR`에 있어요.
- 메뉴 사진: 아래 '메뉴 사진 넣기'를 보세요.
- 이 폴더만 따로 실행해 보려면: `npm install` → `npm run dev`
